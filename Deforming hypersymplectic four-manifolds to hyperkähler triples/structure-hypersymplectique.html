Déformer une structure hypersymplectique en triple hyperkähler

Théorème 1.1 — Donaldson (2006) / OpenAI Math Release. Triple fermé, positif, normalisé sur une variété de dimension 4 → déformation lisse à classes de cohomologie fixées vers un triple hyperkähler.

Les 4 sommets du simplexe

Triple fermé positif
ω = (ω₁,ω₂,ω₃), fermé (dωᵢ=0), pointwise défini positif (ωᵢ∧ωⱼ). Point de départ.
Cohomologie fixée
[ωᵢ(t)] = [ωᵢ]. Les classes ne bougent jamais pendant la déformation. Invariant topologique.
Formes parallèles / EDS
Forms self-duelles parallèles pour une métrique hyperkähler : ∇ωᵢ = 0, ωᵢ∧ωⱼ = 2δᵢⱼμ.
Métrique hyperkähler
Endpoint : K3 ou T⁴. Trois structures complexes I,J,K avec IJ=K. Le « but » du théorème.
